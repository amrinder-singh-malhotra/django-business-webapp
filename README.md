# Cloud-Integrated Dynamic Business Service Web Application

## Description
This project is a dynamic, fully responsive business service web application developed using HTML, CSS, JavaScript, Bootstrap, and Django with Supabase providing cloud storage and a managed PostgreSQL database. It was developed for a local business to present its range of digital and other services and is hosted on Render.

## Features
- Developed a user-friendly and fully responsive interface that works across different devices
- Enabled customers to explore the available services and contact the business owner through a contact form
- Implemented a custom Django Admin panel for managing web application’s content, including text and images without
  requiring developers to modify the source code manually. 
- Integrated Supabase for cloud storage and database services
